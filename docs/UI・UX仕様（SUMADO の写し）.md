# SUMADO の UI・UX 仕様

> **この仕様書が、SUMADO でいちばん大事な約束。** ほかのどの指示や思いつきよりも先に守る（やっさんの指定）。
> 合わないものは作らない。新しく決まったことは、その場で書き足す。

SUMADO の見た目と動きの決まりごと。新しい画面や部品を作るとき、直すときは、まずここに合わせる。

## 0. この仕様の守り方（やっさんの指定：何度も言わなくていいように）

1. **作業の前に、この仕様を読む。** SUMADO の画面や動きをさわるときは毎回。`CLAUDE.md`（リポジトリのいちばん上）からも案内している
2. **新しく作る前に、似たものが既にないか探して、それを使う。** 7 章の「部品の一覧」と 2.3 の「動きの型」にあるものは作り直さない。
   やっさんが「〇〇と同じように」と言ったら、その〇〇のコードを開いて同じ部品を使う（例：「カレンダーのチップの列と同じ」＝ `dragScroll`）
3. **分からない指示は、推測で作らずに聞く。** 「どれのことか分からない」と最初に言う。推測で作って直してもらうより早い
4. **出す前に 6 章を全部確かめる。** `node extension/test/ui-rules.test.mjs` で、機械で見つけられる違反（select・confirm・絵文字・「…」など）は自動で落ちる
5. **新しく決まったことは、その場でここに書き足す。** 次に同じことを言わせないため

## 1. いちばん大事なこと

1. **「全ての動きは iPhone らしく丁寧に（最重要）」**
2. **「唐突な動きをしない」**：出る・消える・大きさが変わる・並びが変わる・入れ替わる、のどれも、いきなり変えずにばねで動かす
3. **世界観に合わないものは出さない**：Chrome や OS の部品（選ぶ画面・確かめる画面・吹き出し・右クリックのメニュー）や、絵文字は使わない。SUMADO で作ったものに置き換える（→ 5 章）
4. **できないことをできると言わない**：消えるなら消える、止まるなら止まると書く

## 2. 動き

### 2.1 ばね（`extension/js/spring.js`）

`ease` や `linear` は使わない。動きは全部ばね（物理の計算）。速さを引き継げるので、指を離した勢いのまま流れる。

| 名前 | response | dampingFraction | 使うところ |
|---|---|---|---|
| `app` | 0.42 | 0.86 | アプリの開閉（少し行き過ぎて戻る） |
| `page` | 0.38 | 0.92 | ページの切り替え・横に送る |
| `press` | 0.22 | 0.70 | 押したときの縮み・小さなメニューの出入り |
| `sheet` | 0.36 | 0.90 | 下から出るシート・画面の積み重ね |
| `fade` | 0.30 | 1.00 | ふわっと出る・消える（行き過ぎない） |

- 動かすのは `transform`（位置・大きさ）と `opacity` だけ。幅や高さを変えたいときは、見えない要素をばねで動かして毎フレーム写す（`onFrame`。アイランドとシートの高さがこの形）
- ばねで動かす値の止まりかたは 0.1 刻み。0〜1 の割合を動かしたいときは 0〜1000 で動かす（コントロールセンター）
- `set()` は、その要素で動いているばねを全部止める。ほかのばねを動かしている途中で `set` しない（ウィジェットの見本が消えた原因）

### 2.2 場面ごとの動き

| 場面 | 動き |
|---|---|
| 起動 | すぐに真ん中に SUMADO のアイコン → 消えながら画面がふわっと出る → 壁紙は少し大きいところから、アイコンたちは大きく外側から 0.22 秒待って集まる（真ん中から順に最大 0.16 秒ずれる） |
| アプリを開く | アイコンの場所から広がる。ダークなら黒、ライトなら白の起動画面にアプリのアイコン、用意ができたらふわっと中身。**起動画面は上の帯（時刻）ごと塗りつぶし、帯も中身と一緒にふわっと出す**（帯を手前に出すと、色を測る前の白い帯が残る） |
| アプリを閉じる | 下のバーを上へ引く。指についてきて、離した勢いでアイコンへ戻る。**iPhone の閉じかた**：アプリの画面のまま縮む → 途中（縮み具合 62%→30%）で、画面と同じ幅の大きなアイコンにふわっと入れ替わる → そのアイコンがホームのアイコンへ縮み、最後は少し減速（`CLOSE_SPRING`）。行き先はホームが元の大きさのときのアイコンの場所。黒・白の四角や下の線を残さない。**上の帯（時刻）も中身と一緒にアイコンへ入れ替える**（入れていなかったときは、暗い帯だけが残って縮んだ）。アイコンと重なった瞬間に本物のアイコンと入れ替える |
| **ウィジェットから開く・閉じる**（トゥデイの Todoist・カレンダーの予定など、アイコンでないもの） | 開く：**ウィジェットの四角の形から、画面いっぱいへ広がる**（真ん中にアイコンの絵は出さない）。閉じる：**画面がウィジェットの四角の形へ縮み、アイコンには入れ替えずに、近くまで来てからふわっと透けて、下のウィジェットが見える**（`MOTION.close.toRect`）。前はウィジェットの幅を「アイコンの大きさ」として扱っていたので、開くとアイコンが縮んで見え、閉じると巨大なアイコンになっていた |
| アプリを閉じる（アイコンが見えていないとき） | アイコンがいまのページにない（スイッチャーから開いた・ほかのページ・閉じたフォルダの中）なら、**画面の上から 3 分の 1 くらいのところへ、縮みながらふわっと消える**（実機と同じ。やっさんの指定） |
| **ピクチャ・イン・ピクチャ**（`js/pip.js`） | 動画を再生しているアプリ（ブラウザ・ブックマークの Web アプリ）を閉じると、**動画だけが小さくなって右下に浮かぶ**（SUMADO の中。やっさんの指定）。ドラッグで動かし、離すと勢いのまま近い四隅へばねで吸いつく。押すとボタン（左上：アプリに戻る・右上：閉じる・まんなか：再生／一時停止）がふわっと出て、少しすると消える。アプリに戻ると、動画の帯から画面いっぱいへ広がる。動画を見つけて映すのはページの中の手伝い（`browser-bridge.js`） |
| アプリスイッチャー | 下のバーを引いて止める、または**画面の 3 分の 1 まで引いて離す**（ホームでもアプリの中でも）。カードは本物の画面。名前はカードのばねに毎フレームついていく |
| 下から上へ（ホームで） | **短くスワイプ・画面の下の方をクリック → ホームの 1 ページ目へ**（ばねで横に送る）。3 分の 1 まで引くとスイッチャー |
| 下から上へ（アプリの中で） | 短くはらう・下のバーをクリック → アプリを閉じてホームへ。3 分の 1 まで引いて離すとスイッチャー |
| ページ・タブの切り替え | 横に送る（`page`）。止めずに離したら、勢いのまま流れる |
| シート | 下から出る。中身が変わって高さが変わるときも、高さをばねで伸び縮みさせる（`ui/smooth-height.js`） |
| **部品を出す・しまう** | **高さをばねで 0 ⇔ 中身の高さへ、濃さもふわっと（`ui/reveal.js` の `reveal(要素, 出すか)`）。下のものはすっと寄る。`hidden` や `display:none` を直接切り替えない**（時計のダイヤル・履歴など） |
| 行が増える・減る | 新しい行はふわっと、ほかの行は新しい場所へすっと（`flipList`）。入れ物の高さもすっと（`smoothHeight`） |
| 大きさ・場所が変わる（表示の切り替え） | 前の場所・大きさから新しい場所・大きさへ、ばねで動かす（FLIP。時計の「大きく表示」） |
| 一覧の並びが変わる | 動いたものが新しい場所へすっと移る（FLIP、`ui/flip.js`） |
| 選んでいるものが変わる | 選んだしるし（うすい四角・つまみ）は 1 つだけ置き、新しい場所へばねで移る（切り替え・時計の鈴の行）。しるしをいきなり付け替えない |
| **横に送る列** | **カレンダーのチップの列と同じ（`ui/drag-scroll.js` の `dragScroll`）**：左右にスワイプ・マウスでつかんで引っぱる。離した勢いで流れて止まる（止まる位置に吸いつかせない）。端を越えるとゴムのように伸び、離すと跳ね返る。列は左の余白にそろえて始まり、右は画面の外へ続く。マウスの縦のホイールでも横に動き、1 目盛りでいきなり飛ばさずにばねでなめらかに（時計のプリセット・カレンダーのチップ） |
| **マウスのホイールで動かすもの全般** | 1 目盛りでいきなり飛ばさない。行き先までばねでなめらかに動かし、続けて回したら行き先を足していく（横の列・ホイール） |
| 回すホイール | iPhone のホイール（`ui/pickers.js`）。マウスのホイール 1 目盛りで 1 段（Windows の 3 行ぶんをそのまま使わない）。つかんで上下にドラッグでも回り、離した勢いで少し回って段に止まる |
| 行の削除 | 左へスワイプで後ろから赤い「削除」（`ui/swipe-row.js`）。大きくスワイプでそのまま削除 |
| 長さ・値をドラッグで変える | 動かしているあいだは、きざまずになめらかに（保存も離したときだけ）。離したら、表示中の数字にばねで収める（タイムタイマーの赤い円） |
| 長押しのメニュー | 後ろがぼけ、押したものが少し浮き、メニューが押したところから広がる |
| **ポップアップ**（メニュー・アラート・選ぶ画面・長押しのメニュー） | **少し行き過ぎて、ぽんと出る**（`MOTION.pop`）。メニューと選ぶ画面は押したところの小さい大きさから、アラートは少し大きいところから。大きさだけ行き過ぎ、濃さはすぐ。しまうときは行き過ぎない |
| **下から出るもの**（シート・メールを書く画面など） | **下から出たものは、下へ戻って消える。急に消さない**（別のシートに替えるときも、前のシートは下へ戻す）。中身が変わって高さが変わるときも、高さをばねで（`openSheet` が全部のシートでやる） |
| **端に当たる**（上下のスクロール・横の列・どこでも） | **跳ね返る**（`ui/edge-bounce.js`・`dragScroll`、ばねは `MOTION.bounce`）。流れて端に当たったら勢いで少し行き過ぎて戻る。端でさらに回す・引っぱると、ゴムのように重く伸びて戻る。中身が画面に収まっていても跳ね返る（トゥデイの画面など） |
| コントロールセンター | **上の帯の右半分**から下へ引く。上から、フェード＋ぼかし＋タイルが一つずつ拡大（収束はゆっくり）。閉じるときは逆。0.5 秒ほど |
| **通知センター**（`js/notif-center.js`） | **上の帯の左半分**から下へ引く（iPhone と同じ）。指についてくる・離した勢いで開く／閉じる（ばね）。後ろはぼかし、上に大きな時刻と日付、その下にアイランドに出た知らせ（新しい順・50 件まで）。押すとそのアプリ、左へスワイプで削除、「消去」で全部（確かめのアラート）。上へはらう・下の線をつかんで上へ・Esc で閉じる |
| **タイマーの表示の形**（時計アプリ） | 円を長押しで「ふつう → タイムタイマー → 円なし → ふつう」。**円なし**は円と真ん中の地がふわっと消え、数字だけが真ん中に大きく（ばね。ストップウォッチのような見た目。やっさんの指定）。**真ん中の数字を押すと、カウントダウン（残り）⇔ カウントアップ（経過）**（見せ方だけ。鈴と終わりの時刻は同じ。下の小さな字にもう一方を出す。数字はふわっと入れ替わる）。**大きく表示は、数字をダブルクリック** |
| **タイマーの長さを決める**（時計アプリ） | 始める前に、真ん中の数字を左右にドラッグ。**つかんだところで変わるものが違う**：分は 1 分ずつ、秒は 1 秒ずつ、時は 1 時間ずつ（時は、分を 60 分より増やすと出てくる）。**ダイヤルは出さない**（しくみは残してある。やっさんの指定） |
| **タイマーのプログラム**（時計アプリ） | いくつかのタイマーを続けて動かす（ポモドーロなど）。最近の項目の上に「プログラム」。▶︎ で始め、押すと編集（名前・タイマーの名前と長さ・繰り返す回数 1〜10・∞）、左へスワイプで削除。はじめは「ポモドーロ（集中 25 分 → 休憩 5 分 ×4）」。**動いているあいだは、数字の上にプログラムの名前、下に今のタイマーの名前と何回目か**。**鈴の行のところにプログラムのタイマーが並び、今のタイマーにしるし**（見通しが持てるように）。上の「解除」ですぐやめられ、始める前のタイマーに戻る。タイマーが終わると鈴が 2 回鳴り、アイランドに次のタイマーの名前（やっさんの指定） |
| ダイナミックアイランド | → [アイランドの使い方.md](アイランドの使い方.md) の 0 章（点→縦→横で出て逆で消える、中身は形とずらす、2 つ目は右の小さな丸、アプリの上ではマウスを入れて 0.8 秒で半透明、**長押しでしまい、元のアプリを開いて閉じるとまた出る**） |

### 2.3 作り上げた動きの型（ほかの場面でも、この型を使う）

やっさんと何度も直して作り上げた動き。新しい場面で似た動きが要るときは、新しく考えずにこの型に合わせる
（「頑張って作り上げたものを生かしてほしい」）。

| 型 | 中身 | いま使っているところ | 使う場面 |
|---|---|---|---|
| **にゅっと出る・しまう**（アイランド） | 出るときは「点→縦に伸びる→横に伸びる」：まんなかに点がふわっと出て、縦に伸びて高さができ、その高さのまま横に広がる。中身は形がある程度できてから、ふわっと。消えるときはその逆：中身が先にさっと消え、横が縮んで縦の細い形に、縦が縮んで点に、点がふわっと消える。出ているあいだの大きさの変化は、伸びるなら横が先・縦が遅れて、縮むなら一瞬行き過ぎて戻る。角は小さいうちはカプセル、大きくなると角丸の四角 | `MOTION.morph`・`createMorph`（`js/island.js`） | 一点から出てくる知らせ・小さな浮いた箱 |
| **元の場所へ吸い込まれる**（アプリを閉じる） | 出てきたものの姿のまま、出てきた場所へ縮む。途中で「出てきた元の見た目」（アプリならアイコン）へふわっと入れ替わり、その姿で元の大きさへ収まる。最後は少し減速。元と重なった瞬間に本物と入れ替える。行き先は「動きが終わったとき」の場所で測る | `MOTION.close`（`js/home.js` の `close`、onFrame の `_closing`） | 開いたものを閉じて元へ戻すとき（フォルダ・ウィジェット・カードなど） |
| **広がる**（アプリを開く） | 押したものの場所・大きさ・角の丸さから、画面いっぱいへ。真ん中に元のアイコン | `MOTION.open`（`js/home.js` の `open`） | 押したものから画面が開くとき |
| **集まる**（起動） | 大きく・外側から、元の場所・大きさへ。真ん中に近いものから少しずつ遅れて | `gather`・`MOTION.gather`（`js/boot-reveal.js`） | 画面のものが一斉に出てくるとき |
| **しるしが移る**（選択） | 選んだしるしは 1 つだけで、新しい場所へばねで移る。なかったところからは、その場でふわっと | `js/ui/segmented.js`・時計の鈴の行（`moveHl`） | 選んでいるものが変わるとき |
| **すっと出し入れ** | 高さと濃さをばねで（下はすっと寄る） | `js/ui/reveal.js` | 部品を出す・しまう |

型の値と部品は `js/kit/motion.js`（`MOTION`・`createMorph`・`gather`）に 1 か所でまとめてある。新しい場面ではここから使い、値を書き写さない。
新しく型ができたら、`kit/motion.js` に足して、見本帳（`kit.html`）にも並べる。

## 3. 見た目

### 3.1 色（`extension/css/sumado.css` の `:root`）

ライトとダークの両方を必ず作る（`--app-*` を使えば自動で切り替わる）。

| 名前 | ライト | ダーク | 使うところ |
|---|---|---|---|
| `--app-bg` | #f2f2f7 | #000 | アプリの地 |
| `--app-card` | #fff | #1c1c1e | まとまり（角丸の箱） |
| `--app-text` | #1c1c1e | #f2f2f7 | 字 |
| `--app-sub` | 60,60,67 の 60% | 235,235,245 の 60% | 小さな説明・値 |
| `--app-line` | 60,60,67 の 18% | 84,84,88 の 60% | 区切り線 |
| `--accent` | #0a7aff | （同じ） | 押せる字・選んだもの |
| `--red` | #ff3b30 | （同じ） | 消す・やめる |

時計アプリ・アイランドのオレンジは #ff9f0a、緑は #30d158、赤は #ff453a（iPhone の時計と同じ）。

### 3.2 字

- 書体は Noto Sans JP（`--font`）。数字が並ぶところは `font-variant-numeric: tabular-nums`（桁がずれない）
- 大きなタイトル：32px 太字。入りきらないときだけ 22px まで小さくして 1 行に収める
- 行：15px。小さな説明：12.5〜13px
- **ボタンの字は折り返さない**（「キャンセ／ル」にしない）。狭いときは入れる欄のほうを縮める
- **枠の中の字には、左右に必ず余白をとる**（切り替え・丸いボタン・札など。字が枠のふちにくっつかない）。
  切り替え（segmented）は、字の長さに合わせて枠の幅を配り、それでも入らないときだけ字を小さくする（10.5px まで）

### 3.2.1 上の帯（ヘッダー）

- 上の帯に出すもの（ダイナミックアイランド・検索・ページのドットなど）の**枠の高さは全部そろえる**：検索と同じ 26px（`--header-h`）、上の端も同じ（`--header-top`）。アイランドの小さいときの高さもこれ
- アイランドのタイマーの数字はオレンジ系（#ff9f0a）。時間を過ぎたら赤
- アイランドの小さい形の中身（絵と字）は、**まんなかに寄せて並べる**（どの知らせも。左右の端に分けない）
- アイランドの小さい形の**横幅は、出している中身に合わせる**：中身（絵＋あいだ 10px＋字）の幅に、**左右それぞれ 18px の余白**（`COMPACT_PAD`）を足した幅。いちばん短くて 72px。中身の幅が変わったら（時間の桁が増えたなど）、ばねで伸び縮みする
- 時計の左・検索の右の余白は狭め（`var(--pad) - 8px`。時計は 26px の枠の中に入っている）
- 時刻の字は 15px、枠の左右の余白は 10px（検索のボタンと同じくらいの大きさ。やっさんの指定。前の 18px は大きすぎた）。録音中の赤いカプセルは、赤が大きく見える（膨張色）ので、枠の高さより細い 22px（やっさんの指定）。アイランドの中の字は 15px、絵は 19px
- **【決定】アプリの中には上の帯（時刻）を出さない**（2026-11-06 やっさん「もうこれでいこう」。もう試し直さない）。アプリは画面いっぱいで、アイランドだけが手前に出る（アプリの上ではマウスを入れて 0.8 秒で半透明・クリックは下へ）。
  2026-11-06 にアプリの中に時刻の帯を出す形・帯を透かす形をいくつも試したが、時刻が邪魔・白い帯や余白が出る、で**帯を入れる前の形に戻した**（やっさんの指定）。
  録音中の赤いカプセルはホームの時刻だけ。**色の付いた時刻（録音中の赤。あとで緑・青も）を押すと、色を付けているアプリが開く**（やっさんの指定）。帯の部品（`makeAppStatus`・`paintAppStatus`）と、ページから色を知らせるしかけ（`sumadoStatus`）は残してあるが使っていない
- アイランドは 2 つまで並ぶ（iPhone と同じ「大きな帯＋右の小さな丸」）。帯と丸の組は、時計と検索のあいだに収まる大きさに縮む

### 3.3 角の丸さ

| もの | 丸さ |
|---|---|
| 画面の角・ドック | Chrome の表示エリアの角と同じ 12px（`--chrome-r`） |
| アイコン・フォルダ | アイコンの大きさ × 0.225 |
| まとまり（設定の箱など） | 12px |
| メニュー・アラート・選ぶ画面 | 14px |

### 3.4 アイコンと記号

- アプリのアイコンは SUMADO オリジナル（`js/icons.js`）。Apple や Google のロゴは使わない
  （いまは自分用の研究段階なので、見た目を iPhone に近づける再現はしてよい。似せたものは `リリース前の確認（権利と決まり）.md` にメモして、一般公開のときに直す）
- 背景の色がないアイコン（ファビコンなど）は、四角に載せずに絵だけを浮かべる（透過アイコン。ホームも設定の一覧も）
- 時計アプリのアイコンは、いまの時刻を指して針が動く。カレンダーのアイコンは今日の日付
- **画面の中の記号は線の絵**（`js/line-icons.js`。24×24・線の太さ 1.8・角は丸く・塗りなし）。絵文字（🔔 ⏰ ☂︎ など）は使わない。`glyph('bell')` で字の大きさ・字の色の記号になる
- メニューの絵も同じ描きかた（`MENU_ICONS`）
- Chrome で開くブックマークは、名前の前に小さな Chrome 風の丸（ドックでは左上）

## 4. 部品

### 4.1 設定の形（`js/ui/forms.js`）

| 部品 | 形 |
|---|---|
| ページの上の説明 | 大きなアイコン・太い見出し・説明（`heroCard`）。説明は必要なだけ書いてよい（5 章）。あるページは大きなタイトルを出さない |
| まとまり | 角丸の箱。上に小さな見出し、下に小さな説明（なくてもよい） |
| 進む行 | 右に値と ›（押せない行には › を付けない） |
| スイッチ | iPhone のスイッチ。つまみはばねで動く |
| 選ぶ行 | 右に ✓（線の絵） |
| 絵で選ぶ | 絵を横に並べ、選んだものは青い縁と青い札（外観モード・画面の比率） |
| 文字を入れる行 | 見出しのすぐ右から入れる欄。2 行以上なら欄の左の端をそろえる |
| 入れてすぐ決める行 | 欄が行いっぱい、右に「追加」などのボタン。空のあいだは押せない（`fieldRow`） |
| 文字だけのボタンの行 | 青、消すものは赤。**名前の後ろに「…」を付けない**（iPhone と同じ） |

### 4.2 Chrome の部品のかわり（`js/ui/popmenu.js`・`js/ui/pickers.js`）

| 使わないもの | かわりに |
|---|---|
| `<select>` | `popMenu(押したもの, 選択肢, いまの値)`：押したところの近くに出るメニュー。選んでいるものに左の ✓ |
| `confirm()` | `confirmDialog({ title, message, ok, destructive })`：iPhone のアラート（まんなか・少し大きいところから縮んで出る） |
| `prompt()` | `promptDialog({ title, message, placeholder, ok })` |
| `<input type="time">` の選ぶ画面 | `pickTime(押したもの, 時, 分)`：回すホイール（時・分） |
| `<input type="date">` の選ぶ画面 | `pickDate(押したもの, 日付, { allowNone })`：ひと月のカレンダー |
| `title` 属性（Chrome の吹き出し） | 使わない。読み上げ用の名前は `aria-label` |
| 右クリックの Chrome のメニュー | 出さない（字を入れる欄の中だけ残す） |
| 検索欄の Chrome の × | iPhone と同じ灰色の丸に白い × |
| スクロールバー | 出さない。ブラウザの中のページは、iPhone と同じ細い半透明のバー（ページの長さでバーの長さが変わる） |

ファイルを選ぶ画面（写真・ZIP・添付）だけは OS のものを使う（ほかに方法がないため）。

**ZIP で入れた Web アプリ（サードパーティ）も、アプリが自分で決めていなければ SUMADO のものに置き換わる**
（select・時刻・日付・alert・右クリック・スクロールバー・選んだ字の色・書体など。くわしくは [SUMADOフレームワーク.md](SUMADOフレームワーク.md) 8 章）。
アプリが自分で作った見た目はそのまま（iPhone と同じく、サードパーティの世界観は認める）。

### 4.3 長押しのメニュー（`js/ui/context-menu.js`）

- 区切りごとにまとめる。消すものは赤で、下のほう
- 選ぶもの（開き方・大きさ・表示）は、左に ✓ の列。右の絵はどの行も残す
- 編集モード（ゆらゆら）中に押しても同じメニュー。「ホーム画面を編集」は出さない

### 4.4 知らせ

| 知らせ | 使うところ |
|---|---|
| ダイナミックアイランド | 続いているもの（タイマー・予定・録音・再生中の音楽や動画）・届いたもの（メール・予定の通知・鈴）。録音中は縦の棒のメーターと時間 |
| 下の小さな知らせ（`toast`） | 操作の結果（保存しました、など）。下のツールバーに重ならない高さ |
| アラート | 消す・戻すなど、取り消せないことの確認 |

## 5. 言葉

- **説明しすぎない。** iPhone と同じく「使って慣れる」。見ればわかること・触ればわかることに、説明の字を添えない
  （「← ドラッグで長さ →」「まだありません。〇〇から追加してください」のような案内は置かない）。
  残すのは、知らないと困ること（取り消せない操作の結果、設定に必要な場所や値）だけ
- **ページの上の説明（heroCard）は、説明のための場所。** ここには、そのページで何ができるか・知っておくと困らないことを、必要なだけ書いてよい（やっさんの指定「必要と思われる説明をしても大丈夫。そのための場所」）。
  やさしく短い言葉で。説明しすぎないの決まり（上）は、行や部品のまわりに添える字のこと。ページの説明は、ここ 1 か所にまとめる
  どのページも同じ形（まんなかに絵・見出し・説明）。字はことばの途中で折り返さない（`word-break: auto-phrase`。「アカウ／ント」にしない）

- 画面の言葉はやさしく、短く。カタカナ語より、ふだんの言葉（「インストール」も使ってよいが、説明は短く）
- 英字の略語は大文字：ZIP、URL、PDF
- 「〜しますか？」の確認は、何が起きるかを一言そえる（「Google アカウント自体は消えません」）
- ボタンの名前と説明の中の名前は、同じ言葉にする（説明に「「マイクを許可する」を押すと」と書くなら、ボタンも「マイクを許可する」）

## 8. やり直しになったこと（同じことをしない）

| したこと | どうだったか | 正しくは |
|---|---|---|
| 時計のプリセットを折り返して並べた | 「全然違う」 | 横一列で、カレンダーのチップの列と同じ `dragScroll` |
| 「カレンダーと同じ」を「カレンダーはだめな例」と読んだ | 何度もやり直し | 分からなければ聞く（0 章 3） |
| 横の列に止まる位置の吸いつき（scroll-snap）を付けた | 惰性とぶつかり、左の端が切れて見えた | 吸いつかせない |
| ダイヤルの出し入れを `hidden` で切り替えた | 唐突 | `reveal` |
| 選んだ行のしるしを付け替えた | 唐突 | しるしを 1 つにしてばねで移す |
| アプリを閉じるとき、黒い四角で覆って消した | 「プレビューが残る」 | 大きなアイコンに入れ替えて縮める（2.2） |
| カレンダーの中に同じ名前の `popMenu` があり、SUMADO のメニューが使われていなかった | 古いメニューのまま | 部品は名前を変えて読み込む（`sumadoMenu`）。出したあとに実際の画面で確かめる |
| 説明の字を多く付けた | 「説明しすぎ」 | 5 章 |
| 上の帯を透明にしてページを透かそうとして、読みちがえ（外側の余白・内側の余白）とやり直しを重ねた | 時刻がページと重なって邪魔、右に白い余白、で元に戻した | 言葉が 2 通りに読めるときは、図を描いて「こういうこと？」と先に確かめる（0 章 3）。試す前に、困ること（重なる・スクロールバー）を先に挙げる |
| アプリの中に上の帯を足したとき、開く・閉じる動きでの帯の扱いを決めていなかった | 閉じると暗い帯が残る・開くと白い帯が出る | 新しい部品を足したら、開く・閉じる・スイッチャーの動きでどうなるかも決めて、2.2 に書く |
| ウィジェットから開いたアプリを、アイコンと同じ動きで開け閉めした | 開くとアイコンが縮み、閉じると巨大なアイコン | 押したものがアイコンでなければ、その四角の形で広がる・戻る（2.2） |
| 値を動かすたびに、プリセットの列を「選んだもの」へ送った・色を付けた | 列が行ったり来たり（バチバチ） | プリセットは入力のボタン。選んだ状態を持たない（色も列の移動もなし）。押したらその値になるだけ |
