# ディクテーションの UI・UX 仕様

> **画面をさわる前に読む。** やっさんと決めた見た目・部品・言葉の決まり。新しく決まったことは、その場で書き足す（書かなかったことは、次の作業で忘れる）。
> 動き（ばね・出し入れ）は SUMADO の仕様書の写し（`docs/UI・UX仕様（SUMADO の写し）.md`）の 1 章と 2 章に合わせる。ここは**見た目と部品と言葉**。
> 2026-11-10 にやっさんの指定「Dictation の UI・UX 仕様に入れておいてほしい」で作った。

---

## 1. いちばん大事なこと

1. **見本で OK をもらったら、見た目も含めて OK と受け取る。** 迷ったら入れる前に聞く
   （v0.24.87〜98 は設定の見本から並びだけ入れ、見た目を入れずにいた。「こうなるんじゃなかったの？」と言われた）
2. **同じ種類のものは、どこでも同じ形にする。** 設定・文脈の小窓・Notion の保存先・右下の小窓で形を変えない
3. **できないことをできると言わない。** 消えるなら消える、送るなら送り先をはっきり書く（「Google」ではなく「Gemini」、「端末」ではなく「この PC の Chrome の中」）
4. **説明しすぎない。** 見ればわかること・触ればわかることに字を添えない。いまある字は一度にまとめて消さず、1 か所ずつやっさんに見てもらって減らす

## 2. 色

ディクテーションの `style.css` の `:root` を使う。新しい色を増やさない。

| 名前 | 値 | 使うところ |
|---|---|---|
| `--bg` | #1a1a1f | 地・設定の箱の中 |
| `--bg-elevated` | #23232a | 小窓（モーダル）の地 |
| `--bg-subtle` | #2d2d36 | 詳細設定の中身の地・カード・一覧の地 |
| `--border` | #3a3a44 | 区切り線・枠 |
| `--text` / `--text-muted` / `--text-faint` | | 名前（白）／説明（小さい字）／いちばん薄い字 |
| `--accent` | #34d399 | 選んだもの・オンのトグル・押すボタン |
| `--heading` | #7dd3fc | 見出しの絵・フォーカスの枠 |
| `--danger` | #f87171 | 消す・取り消せないこと・赤い丸の × |
| `--caution` | #ff9f0a | **注意のしるし**（AI が無いタブ・注意書き）。SUMADO のオレンジ（v0.24.90 やっさん「オレンジ系に」） |

## 3. 記号

- **記号は SUMADO の線の絵**（SUMADO の `extension/js/line-icons.js`。24×24・線の太さ 1.8・角は丸く・塗りなし）。`icons.js` に `sm-` で写して使う（`sm-mic` など）
  （やっさん「シンボル化や使うアイコンセットは SUMADO に収録しているものを使ってほしい」）
- 進む・開く矢印は SUMADO の `GLYPHS.chevronRight`（`sm-chevron-right`）
- 絵文字は使わない
- 前からある `icons.js` の絵（Lucide 風）は、ボタンなどにそのまま残っている。**新しく足すものは SUMADO の線の絵を使う**

## 4. 設定の形（設定・この録音の文脈・Notion の保存先で共通）

見本は `docs/設定の見本.html`（https://claude.ai/artifact/Wp57NXqbyYm6jbLngT6FxQ ）。

| 部品 | 形 | クラス |
|---|---|---|
| まとまりの見出し | 左に SUMADO の線の絵（`--heading`）、15px の太字・白 | `.field-group.settings-section` ＞ `.field-group-title` ＞ `.section-icon` |
| 見出しの下の一言 | 小さい字。まとまり全体の説明はここに 1 つだけ | `.settings-lead` |
| 箱 | 角の丸い箱（12px）、`--bg` の地、`--border` の枠。項目ごとに区切り線 | `.settings-box`（文字を入れる箱は `.form-box`） |
| トグルの行 | **名前は左（白）、説明はその下（小さい字）、トグルは右**。トグルは**名前と説明をあわせたまとまりの上下まんなか**。説明は名前と同じ `<span>` の中に入れる（下の別の段に置かない） | `.field-row` ＞ `input[type=checkbox]` ＋ `<span>名前<small class="field-hint" style="display:block">説明</small></span>` |
| 選ぶ（ラジオ）の行 | **名前は白い太字、説明はその下の小さい字**。ラジオは名前と説明をあわせたまとまりの上下まんなか（「名前 — 説明」と 1 行に並べない） | `.field-row` ＞ `input[type=radio]` ＋ `<span><strong>名前</strong><small class="field-hint">説明</small></span>` |
| 大きく選ぶもの | 絵の付いたカード。選んだものは緑の枠と緑のうすい地。ラジオは見えないところに置き、カードで選ぶ | `.mode-card`（文字起こしのモード） |
| 数字・選ぶ欄（詳細設定） | トグルと同じ。**名前と説明は左の列、欄は右の列で、名前と説明をあわせたまとまりの上下まんなか**（説明は欄の下にはみ出さない・v0.24.108）。選択肢の字が長いときは欄のほうを縮める。**例外:「音声ファイルの取り扱い」は、名前の下に欄を行いっぱい・説明はその下**（選択肢の字が長いため。やっさんの指定） | `.settings-acc-body label.field`（例外は `.field-block`） |
| 文字を入れる欄 | 名前の下に行いっぱい（長い字・何行もの字を入れるため） | `.form-box label.field` |
| 押すと開くまとまり | 並びは 音声入力・AI の動き・停止条件・録音の保持・表示・Notion 連携・そのほか（v0.24.109 やっさんの指定）。見出しに線の絵と ›。開けると › が下を向く。高さと濃さをばねで（`Motion.reveal`）。毎回たたんだ状態から | `.settings-acc` |
| 状態の字が付くトグル | トグルは右端、状態の字（「使えます」など）は下の行 | `.toggle-with-status` |
| 表（使用するAI） | 丸を押して選ぶ。選べない丸は点線。**一緒に変わる行のあいだには線を引かない**。線はまとまりの境目だけ（v0.24.100） | `.ai-table` |
| 注意書き | オレンジの ⚠（`sm-warn`）と太字の見出し、その下に小さな一言 | `.ai-caution` |
| 消せるものの × | 名前の左の赤い丸に白い ×。押したら確認の小窓 | `.clear-chip` |
| 一覧の行（保管している録音） | 名前（白）と日時・大きさ（小さい字）は左、トグルとボタンは右。行は区切り線で分ける | `.recording-row` |
| 使用量のカード | いちばん下。Gemini は大きな数字（今月のトークン）・料金の目安・割合の帯（文字＝`--heading`・音声＝`--accent`・出力＝`--caution`）・働きごとの棒・前の月。Groq は**残りの輪を 3 つ**（上に大きく「今日の音声」、下に「この1時間の音声」「今日の回数」。輪は残りで、使うほど減る。2 割を切ったらオレンジ、使い切ったら赤）。Gemini の数字を長押しすると月別の棒グラフ。記録のリセットは赤い字のボタン＋警告。数字は桁をそろえる（`tabular-nums`）。目安であることと、数えている範囲を小さい字で添える | `.usage-box` |

## 5. 小窓（モーダル）

| 部品 | 形 |
|---|---|
| 確認の小窓 | `confirmDialog({ title, message, ok, destructive })`。見出しは太字、その下に小さな字。消すものは赤いボタンで、うっかり Enter で消さないよう「キャンセル」に指を置く。**ブラウザの `confirm()` は使わない**（残りは TODO の 8） |
| 無音の確認 | 確認の小窓と同じ形（`.confirm-card`・`.confirm-title`・`.confirm-message`） |
| 出入り | 少し大きいところから縮んで、少し行き過ぎて収まる（`installModalMotion`。SUMADO の仕様書 2.2） |

## 6. タブ

| 部品 | 形 |
|---|---|
| AI が無いときのタブ | アイコンがオレンジの注意の絵（`sm-warn`）。メモには付けない。文字起こしは「AI で聞き取る」を選んでいて使える AI が無いときだけ |
| 空のときの案内 | SUMADO の線の絵・一言・受け持つ AI の札（「聞き取り・Groq Whisper」）。AI が無いときは、オレンジの ⚠・見出し「API キーが登録されていないか、有効になっていません」・一言・［AI 設定を開く］ |

## 7. 言葉

- 画面の言葉はやさしく短く。名前は、利用者が知っている言い方で（「使う AI」→「使用するAI」はやっさんの指定）
- 送り先・保存先ははっきり書く（「Gemini に送信」「この PC の Chrome の中に保存（Google ドライブには保存しません）」）
- キーが入っていてもトグルを切っていれば使えない。そのときに「登録されていません」と言い切らない（「登録されていないか、有効になっていません」）
