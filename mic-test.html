マイク同時利用テスト

Web Speech API（即時表示用）と MediaRecorder（Gemini 送信用）が、 同じマイクを同時に使えるかを確かめます。 これが動けば「WebSpeech で表示しながら裏で Gemini に送る」構成が作れます。

手順

  1. 「テスト開始」を押してマイクを許可する
  2. 20秒ほど普通に喋る（何でもよい。「テストです、聞こえていますか」など）
  3. 「テスト終了」を押して、下の判定を見る
Web Speech（即時表示）
未開始
MediaRecorder（録音）
未開始
入力レベル
—
Web Speech が聞き取った文字
（まだありません）

判定

テストを実行してください
